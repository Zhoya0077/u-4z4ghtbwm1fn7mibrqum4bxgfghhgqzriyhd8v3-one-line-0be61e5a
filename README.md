A single funny line, written by `main.ts` to `/output/entry.txt`:

> My password manager forgot my password, so now we're both locked out of my life.

Run: `node main.ts` (Node 22+). It prints the line, writes `entry.txt`, and exits non-zero if the entry is missing, empty, multi-line, or over 140 characters.
